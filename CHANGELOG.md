# Changelog

All notable changes are tracked here. Each slice ships under its own tag (`slice-N-...`); the cumulative v1 release candidate is `v1-rc1`.

## v1-rc1 — 2026-05-17 (Slice 7: Security, Observability & Deploy)

- Global `SecurityHeaders` middleware: HSTS (production only), CSP (enforced in prod, report-only locally with MinIO whitelisted), X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.
- `URL::forceScheme('https')` guarded on `app()->environment('production')`.
- Sentry SDK wired on backend (`sentry/sentry-laravel`) and frontend (`@sentry/nextjs`). DSN-empty defaults to no-op. `SentryEventScrubber` + frontend `buildBeforeSend` redact Authorization, Cookie, password, token, api_key, FAL_API_KEY.
- `/api-docs` page ships `swagger-ui-react` lazy-loaded via `next/dynamic({ ssr: false })`; bundle stays out of every other route's payload.
- OpenAPI cleanup: controller `OA\Path` annotations are now bare; `OA\Server(url: '/api/v1')` is the single source of truth; the frontend `rewritePath` shim is gone.
- `.github/workflows/deploy.yml` triggers on `v*` tag push (Railway deploy → migrate → frontend deploy → healthcheck).
- `BackgroundLayer` switches to `next/image`; layout font `display: 'swap'`; remaining lint warnings reduced from 7 to 4 (all justified).
- `make smoke` and `make deploy-prod` targets; `CHANGELOG.md` and v1-rc1 status badge.

## slice-6-e2e-perf-polish — 2026-05-16

- Playwright suite (4 specs) covers SPEC §17 items 1–9 via the full docker compose stack.
- ULID externalization: fish + background ids route-bind on a Crockford-base32 26-char pattern.
- Canvas RAF pre-warms tinted sprites; `await getTintedSprite` no longer stalls the animation loop on cold cache.
- `e2e.yml` GitHub Actions workflow runs the canonical journey on every PR touching `frontend/` or `backend/`.

## slice-5-repo-aquarium — 2026-05-15

- `/repos/{owner}/{repo}/aquarium` endpoints: GitHub repo metadata → deterministic fish school.
- Cached fetch via `Cache::remember` (Redis). `fork-to-my-aquarium` action seeds the authed user's aquarium from the repo's fish set.
- Owner/repo route-pattern hardening: misshaped slugs miss the route table and 404.

## slice-4-backgrounds — 2026-05-14

- Background upload (Intervention Image re-encode, ≥ 1280×720 enforced) → R2/S3 disk.
- Fal AI text-to-image background generation with per-user and global rate limits.
- One-active-background-per-user invariant enforced via partial unique index + 409 on race.

## slice-3-fish-canvas — 2026-05-13

- Fish CRUD: nickname, breed, color, size; ULID externalized later in slice 6.
- Full-viewport `<canvas>` with RAF loop; `currentColor` sprite tinting via `getTintedSprite`.
- `useAquariumStore` Zustand store; hover/feed/edit/delete interactions per SPEC §17 items 2–5.

## slice-2-auth — 2026-05-12

- Email + password registration with `zxcvbn` strength check; bcrypt hash; Sanctum personal-access tokens.
- Iron-session cookie issued by Next.js `/api/auth/set-cookie`; proxied requests through `/api/proxy/[...path]` attach the bearer.
- Google OAuth (Socialite) with env-flagged enable/disable.

## slice-1-foundations — 2026-05-10

- Docker Compose stack (Postgres + Redis + MinIO + Laravel + Next.js) — `make up`.
- Laravel 13 + Next.js 16 baselines; Pest + Vitest + Larastan + ESLint baseline tests.
- OpenAPI 3.1 spec generated by `l5-swagger`; typescript-fetch client generated by openapi-generator.
- CORS scoped to `FRONTEND_URL`; basic `/api/v1/health` route.
